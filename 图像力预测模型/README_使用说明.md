## 项目简介
输入一张物体图片，模型自动识别物体类别，并预测该物体的安全抓取力范围
（最小抓取力 = 再小就掉落；最大安全力 = 再大就损坏）。

~~项目包含**两个版本**的模型，均已训练好可直接使用~~（权重已删除，仅存代码）：

| 版本 | 脚本 | 输入 | 模型文件 | 说明 |
|------|------|------|----------|------|
| 单流版 | predict.py | RGB 图片 | grasp_force_model.pth | ResNet18 多任务（分类+回归） |
| 双流版 | predict_dual.py | RGB + 深度 | grasp_force_model_dual.pth | RGB 纹理流 + 深度几何流融合 |

## 双流网络说明（RGB + 深度）

```
RGB 图片 ──> ResNet18(ImageNet预训练) ──> 512维纹理特征 ─┐
                                                        ├─拼接─> 分类头(6类)
深度图片 ──> ResNet18(单通道,从头训练) ─> 512维几何特征 ─┘      └─回归头(min/max力)
```

- **RGB 流**负责颜色、纹理、材质外观（是玻璃还是塑料主要靠它）
- **深度流**负责几何形状、厚度、尺寸（辅助判断物体的质量与形变特性）
- 训练时的几何增强（翻转/旋转/平移）对 RGB 和深度同步施加，保证像素对齐

**深度图从哪来？**
1. 合成训练图：`generate_depth_maps.py` 自动生成（物体掩膜 → 圆顶状厚度），存在
   `train_depth/`、`test_depth/`
2. 预测时若图片同目录有 `<文件名>_depth.png` 会自动使用（真深度，推荐 RGB-D 相机拍摄）
3. 没有深度图时，脚本会从 RGB 自动估计一个**伪深度**（中心先验+边缘能量），
   仅保证管线可用，精度不如真实深度

## 模型性能

| 指标 | 单流版(RGB) | 双流版(RGB+深度) |
|------|-------------|------------------|
| 合成测试集准确率 | 100% (30/30) | 100% (30/30) |
| 力预测 MAE | 约 1.2 N | 0.71 N |
| 真实图片准确率(30张,伪深度) | 26.7% | 20.0% |

说明：真实图片用的是自动估计的伪深度（非真深度），深度流收到的信号与训练分布不一致，
因此真实图准确率没有提升甚至略降——这不是双流架构的问题，而是缺少真实深度输入。
用 RGB-D 相机提供真深度图后，双流版才能发挥全部实力。
合成集上双流版的力预测误差从 1.2 N 降到 0.71 N（约减半），置信度也普遍更高。

详细训练曲线见 training_results.txt / training_results_dual.txt。

### 换一张自己的图片预测
- 把图片放进项目任意位置，复制"双流-预测-单张示例"配置，
  把 `--image` 后面的路径改成你的图片路径，F5 运行
- 若有 RGB-D 相机：把深度图存成和图片同名的 `<文件名>_depth.png` 放同目录，
  脚本会自动使用真实深度（输出里会标注"深度来源"）

## 常见问题

**Q：终端里中文显示乱码？**

**Q：提示找不到 torch 或 depth_utils？**
A：检查右下角解释器是否为 E:\Python39\python.exe；
   如果之前设过 PYTHONPATH 环境变量，把它删掉。

**Q：双流预测报"找不到 grasp_force_model_dual.pth"？**
A：先运行"双流-训练模型"配置生成权重文件。

## 注意事项
1. 全部环境在 E 盘，未占用 C 盘
2. 合成图用于验证算法流程；真实照片准确率偏低属正常（域差异）
3. 提升真实图片准确率的方法：把真实照片按类别放进 train_images\<类别>\，
   再跑"训练模型"重新微调（单双流均可）
4. 伪深度只是应急方案；要发挥双流网络全部实力，请用 RGB-D 相机提供真深度图
5. 力值单位为牛顿(N)，基于 RCT/OopsieVerse/SoftVTBench 等数据集综合标定

## 技术细节
- 骨干网络：ResNet18（RGB 流用 ImageNet 预训练并冻结至 layer4；深度流从头训练）
- 特征融合：两路 512 维特征拼接 → 1024 维
- 分类头：Linear(1024->256->6) + CrossEntropyLoss
- 回归头：Linear(1024->256->128->2) + MSELoss
- 总损失：loss = loss_cls + 0.5 * loss_reg
- 数据增强：同步几何变换（翻转/旋转/仿射）+ RGB 颜色抖动
- 优化器：Adam，初始学习率 0.001，StepLR 衰减
