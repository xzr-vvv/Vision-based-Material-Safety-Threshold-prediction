# fragile_flag 与 ExpForce 分类不一致清单与统一口径

日期：2026-08-21
对应缺口文档：`SafetyVTLA_缺口与可用资源整理_20260821.md` §4.4（决策层缺口）
比对脚本：`数据采集准备\check_flag_consistency.py`（可重跑复核）
官方分类来源：`ExpForce数据集\07_ExpForce_安全抓力范围.csv`（129 物体，含 category 列）

## 1. 比对方法

四个数据源交叉比对：

| 数据源 | 内容 | 分类口径 |
|---|---|---|
| `objects_已有安全阈值.csv`（41 行手填） | fragile_flag / deformable_flag + ref_category | 手填 + ExpForce 参照类别 |
| `数据采集准备\objects_模板.csv` | fragile_flag / deformable_flag / leaf_class | 本地口径（SafetyVTLA 采购清单） |
| `RGB_dataset\labels.csv`（129 个 E 系物体） | category（轻脆/重脆/刚体/柔性） | 本地四分类（训练标签） |
| ExpForce 官方 07 CSV | category（易碎/柔性/刚体） | ExpForce 力程分类 |

本地四分类 → ExpForce 三分类映射：轻脆/重脆→易碎，柔性→柔性，刚体→刚体。

## 2. 比对结果总览

**层面 B（训练标签，最关键）：labels.csv 的 129 个 E 系物体与 ExpForce 官方分类
零不一致（0/129）**。分布：刚体×刚体 61、柔性×柔性 57、易碎×易碎 11
（本地轻脆 3 + 重脆 8 = 官方易碎 11，细分无损映射）。
→ 训练用的 L1/L2 标签不存在与 ExpForce 的口径冲突，无需改动。

**层面 A（阈值表手填 flags）：41 行中 4 行不一致**，其中：
- 2 行是**过时标记**（FRA016/FRA039）——本地模板与 labels.csv 早已改为柔性，
  ExpForce 官方也是柔性，只有阈值表 flags 还停留在易碎 → 已同步修正；
- 2 行是**真实语义分歧**（FRA048/SOF053）——本地与 ExpForce 各有依据，
  保留双口径并存 + 显式标注（见 §3）。

**ref_category 列忠实性核验**：阈值表 41 行的 ref_category 全部与
ExpForce 官方分类吻合（含 E005/E006 纸杯=柔性、E038/E110 Pocky盒=刚体、
E055 瓶装软糖=刚体），无抄录错误。

## 3. 不一致清单（4 项）与处置

### 3.1 FRA016 纸杯（单个）——已修正（过时标记）

| 源 | 分类 |
|---|---|
| 阈值表 flags（改前） | 易碎（fragile=1） |
| 阈值表 ref_category | 柔性 |
| 本地模板 / labels.csv | 柔性（l1_gate=非易碎） |
| ExpForce 官方（E005/E006） | 柔性 |

物理依据：薄壁纸杯的夹持失效模式是**压瘪变形**（可部分回弹），不是脆性断裂；
ExpForce 对纸杯的最小夹持力（0.25N）也是按柔性物体测的。
**处置**：fragile 1→0、deformable 0→1，notes 加 `[0821改]` 审计说明。
F_max 评测参考不受影响（FRA016 走文献实测换算 4.2N；ref_category 本就是柔性，
若走系数占位也是柔性×3）。

### 3.2 FRA039 薄壁塑料杯（一次性）——已修正（过时标记）

同 FRA016：E007 官方柔性、本地模板/labels 柔性，仅阈值表 flags 过时。
**处置**：同上，flags 对齐柔性，notes 加审计说明。
F_max 占位系数本就按 ref_category=柔性取 ×3，不受影响。

### 3.3 FRA048 Pocky 饼干棒（盒装）——保留双口径（真实分歧）

| 源 | 分类 |
|---|---|
| 本地模板 / labels.csv | 轻脆（易碎侧，l1_gate=易碎） |
| ExpForce 官方（E038/E110） | 刚体 |

分歧本质：**两套分类学目的不同**。ExpForce 的三分类是"力程分类"（决定其
安全范围系数 易碎×2/柔性×3/刚体×5），夹的是盒子本身，硬纸盒按刚体处理合理；
本地的 L1 门控是"损伤风险分类"（安全语义），盒内是脆性饼干，过力夹压会
压溃纸盒连带挤断内容物，按轻脆处理是**安全侧保守选择**。
且 FRA048 与 FRA019（袋装薯片）、E040（单片薯片，官方易碎）同属
brittle_snack 族，族内语义一致。
**处置**：本地分类保留轻脆；阈值表 notes 补 `[0821注]` 写明两口径并存及理由。
F_min 参照（E038/E110 实测 1.0N）与分类无关，不受影响；F_max 评测参考走
同族文献换算（4.8N），不走刚体系数，不受影响。

### 3.4 SOF053 软糖（袋装）——保留双口径（参照物不同 + 真实分歧）

| 源 | 分类 |
|---|---|
| 本地模板 | 柔性 |
| ExpForce 官方（E055） | 刚体 |

关键细节：**E055 参照物是瓶装 42 粒装（Goodbye Stress gummies 42 count），
刚体的是塑料瓶**；本地实物是**袋装**，软糖袋受夹明显变形，本地柔性判断
符合实物。这是"同类不同容器"的同型转移，材质差异已在 notes 标注。
**处置**：本地分类保留柔性；notes 补 `[0821注]` 写明容器差异。
已知残留：F_max 占位系数按 ref_category=刚体 取 ×5（3.75N）；若按本地柔性
口径应为 ×3（2.25N）。该列本就是"仅评 gap 上界，非实测"的占位值且已明示，
不改代码；若日后需要更保守的占位，按本地口径取 ×3 即可。

## 4. 统一口径拍板结论

1. **双轨制**：本地四分类（轻脆/重脆/刚体/柔性 + L1 易碎/非易碎门控）服务于
   损伤风险安全语义，是训练与评测的唯一标签口径；ExpForce 三分类仅作为
   力值参照表的来源口径（ref_category）保留，不回写训练标签。
2. **冲突时以本地口径为准**（安全侧保守），但必须在 notes/ref_match_note
   显式标注 ExpForce 原口径，禁止静默覆盖——符合指令文件 §1.3
   "不以物体类别名推断材料"与 §6 自检"不把类别倍数上限冒充损伤真值"的精神。
3. **过时标记必须同步**：阈值表 flags 与本地模板/labels.csv 不一致且无语义
   理由时（FRA016/FRA039 型），以本地为准修正并留审计标记。
4. 交付 SafetyVTLA `objects.csv` 时：fragile_flag/deformable_flag 按本地口径
   填，另附 ref_category 列（ExpForce 口径），4 处（现已 2 处修正 + 2 处
   显式标注）在 notes 说明，满足指令文件 §1.1 字段要求。
