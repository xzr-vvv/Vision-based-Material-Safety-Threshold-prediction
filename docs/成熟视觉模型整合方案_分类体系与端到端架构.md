# 成熟视觉模型整合方案 — 分类体系设计与端到端架构

日期：2026-08-20
输入：本项目全部调研（vision-backbone-survey / rgbd-grasp-force-survey / rgbd-image-datasets / 易碎物体安全阈值预测_专项调研 / A1 实施路径）+ 2026-08-20 Exp-Force 129 物体数据实测分析（本文档第一节）。
回答的问题：**能否实现一个成熟的视觉模型，先预测刚体/柔性/易碎分类（或更细/更粗），再预测安全阈值上下界？分类体系应该怎么设计？**

---

## 一、数据实测：分类体系的选择依据（2026-08-20 对 129 物体全量分析）

### 1.1 三类的物理统计

| 类别 | n | 质量中位 [范围] | F_min 均值±std | k 系数 | μ 系数（dinov3_dual 反推） |
|---|---|---|---|---|---|
| 刚体 | 61 | 279g [2-1384] | 2.11 ± 1.24 N | 5.0 | 0.66 |
| 柔性 | 57 | **18g** [1-396] | **0.79 ± 0.59 N** | 3.0 | 0.22 |
| 易碎 | 11 | 245g [2-635] | 1.09 ± 0.64 N | 2.0 | 0.95 |

三个数据事实：

1. **柔性 vs 刚体几乎可用质量单变量分开**（中位 18g vs 279g；F_min 0.79 vs 2.11N，分布重叠小）——这不是分类难点，合并它的收益低；
2. **易碎 11 物体存在清晰的"轻脆/重脆"两簇**（Exp-Force 官方同为二分法，验证成立）：
   - 轻脆：薯片 2g/0.25N、鸡蛋 62-64g/0.50N（F_min ≤ 0.5N，质量 < 100g）
   - 重脆：果酱瓶→玻璃杯→陶瓷杯→可乐玻璃瓶 145-635g/0.75-2.5N
3. **类别错误的代价不对称**：漏判易碎（当非易碎抓）→ 碎裂，不可逆；误判易碎 → 力偏小 → 滑移，可恢复。**易碎检测必须召回率优先。**

### 1.2 "合并刚体+柔性"方案的量化代价（用户提议检验）

合并为"非易碎"后 k 只能统一取值，两个方向都有代价：

- 取 k=5（迁就刚体）：**柔性物体 F_max 高估 67%**（3F→5F）→ 软物压伤风险，危险方向；
- 取 k=3（迁就柔性/保守）：**刚体 F_max 低估 40%**（实测均值）→ 操作区间 [F,5F] 缩到 [F,3F]，推荐力贴近滑移边界 → 滑移风险上升；
- 无论取哪个 k，μ 系数混淆（0.66 vs 0.22，物理基线差 3 倍）都存在。

**表面收益**（需警惕）：跨相机测试中柔性 10% 的错误大多是"误判为刚体"，合并后这部分"变对"，总准确率 50%→约 77%。但这是指标美化：被误判的柔性物体拿到了错误的 k 和 μ，**力值输出系统性变差，安全风险不变或上升**。跨相机问题的根因是视角域差，靠合并类别掩盖不了。

**结论：不建议删除柔性类。** 但用户直觉的正确部分是——"会不会碎"这个二元判断确实是安全核心，应该独立成层（见下节方案 C）。

## 二、分类体系三方案对比

| | 方案 A：三类（现状） | 方案 B：二类（易碎/非易碎） | **方案 C：分层四类（推荐）** |
|---|---|---|---|
| 结构 | 刚体/柔性/易碎 一次 softmax | 易碎 vs 非易碎 | L1 安全门控：易碎/非易碎；L2 叶：轻脆/重脆/刚体/柔性 |
| 易碎样本利用 | 11 个混在 3 类里，最弱 | 聚焦但仍是 11 个 | 同左，但门控可用非对称损失压召回 |
| k/μ 精度 | 三组参数 | 一组（粗） | 四组参数，最细 |
| 错误代价控制 | 对称损失，无门控 | 二元可控 | **门控层显式召回优先** |
| 跨相机鲁棒 | 柔性 10%/易碎 0% | 掩盖问题 | 门控 + 域差协议分开治理 |
| 实施复杂度 | 低 | 低 | 中（两个二分类头，反而各只 2 类更好训） |

**方案 C 细节**：

```
                    ┌─ 轻脆（薯片/鸡蛋: F_min≤0.5N）→ k=2.0, μ=0.95, 低质量先验
输入图片 ─> L1 门控 ┤
  (易碎?)  └─ 是 ──┘
    │
    └─ 否 ─> L2b: 刚体（k=5.0, μ=0.66）vs 柔性（k=3.0, μ=0.22）
              （质量中位 279g vs 18g，视觉+质量双线索，易分）
```

- L1 与 L2 并非硬串行：实现上是**一个共享骨干 + 三个头**（门控头 / 易碎细分头 / 非易碎细分头），训练时联合，推理时按层次解读；
- L1 阈值可调：部署时把判定阈值向"易碎"侧偏移（牺牲精确率换召回），审计日志记录两边概率；
- 不确定时（L1 概率 0.4-0.6 区间）：按易碎处理（保守 k=2.0）+ 输出 unknown 标志（对齐 SAFETYVTLA 规范"模型不确定时必须输出 unknown"）。

## 三、成熟模型端到端架构（整合全部调研结论）

### 3.1 输入 / 输出定义

```
输入:  单张 RGB 图（当前） / RGB-D 对（自采数据到位后）
输出:  {
  L1 门控:  P(易碎), 判定 + unknown 标志
  叶类别:   轻脆/重脆/刚体/柔性 + 置信度
  F_min:    μ ± σ（牛顿，两指总法向力语义）
  F_max:    k(叶类别) × F_min，data_source=推算
  质量估计:  m̂ (g)
  物理基线:  F_phys = m̂·g / (2μ)，与网络预测互验
}
```

### 3.2 架构分层（每一条都有调研出处）

| 层 | 设计 | 出处 |
|---|---|---|
| 骨干 | **DINOv3 ViT-S/L 冻结**，只训头（小样本最强范式，CPU 可训） | vision-backbone-survey：IN-ReaL 90.4，官方推荐冻结+线性探测 |
| 深度流（二期） | DAv2 ViT-L 冻结编码器 + 融合头；**深度流任务升级为壁厚/容许力估计**（物体级 F_max → 空间分布） | dinov3_dual 已建骨架；GraspSense 证明壁厚→容许力可行且不需破损数据 |
| 分类头 | 层次三头（门控/易碎细分/非易碎细分），易碎类损失加权 ~5.5×（61/11） | 本文方案 C；类别不平衡标准做法 |
| 力回归头 | **(μ, σ) 异方差回归**而非点估计：推荐抓力 = μ + z·σ（防滑分位数），封顶 = k·μ | dinov3_dual 现设计；方案报告评价思想 |
| 质量头 | DINOv3 特征 → 质量回归，输出既作分类辅助特征又作物理基线输入 | dinov3_dual 质量头；本文 1.1 节数据（质量是最强分类线索） |
| 物理一致性 | F = m̂g/2μ 与网络 F_min 互验，偏差过大触发 unknown | dinov3_dual 物理基线；DeliGrasp 白盒路线 |
| 残差修正（二期） | 物理基线 + 神经网络残差的混合回归（Hertz 类先验 + 残差项，复合损失） | V2F（IROS 2026）小样本跨域 R²≈0.7 |
| 安全规则层 | L1 召回优先阈值；unknown 保守降级；易碎门控概率写入审计日志 | SAFETYVTLA 规范 |

### 3.3 训练数据组合（三源）

| 数据源 | 角色 | 状态 |
|---|---|---|
| Exp-Force 129 | 主训练集（单流 RGB；易碎二档细分已验证可分） | 已在手 |
| 自采 RGB-D（Gen3 腕相机） | 域对齐 + 深度流激活；三类各 ≥30 物体 × ≥5 图 × 3 次力测 | 数据采集准备/ 清单就绪 |
| 外部 RGB-D（GraspNet 刚体 / TransCG 易碎玻璃 / YCB 柔性半软物） | 图片增广 + Exp-Force 同类标签平移；TransCG 真值深度另用于训练深度质量门控 | 调研完成待下载 |
| 易碎扩充（建议新增） | 可牺牲替代物（乒乓球/果冻/积木，OMRON 协议）+ 真实易碎物增采 + 按力档实测受损率（草莓论文协议）→ **F_max 从推算升级为实测** | 易碎专项调研 P1 建议 |

### 3.4 训练与评估协议（继承既有结论）

1. 切分：按 object_id / family_id 隔离，禁止同物体图片跨 train/test（SAFETYVTLA A 级）；
2. 跨相机：复刻 Exp-Force 采集协议（俯拍/素色背景/物体占满画面）采集目标相机图，固定 30 张外来测试集持续评测（eval_cross_camera.py）；
3. 指标体系：
   - 门控层：**易碎召回率（安全关键指标）**、精确率、unknown 率
   - 叶类别：四类准确率（对照旧三类基线 88%）
   - 力值：F_min MAE（对照 0.60N）、区间覆盖率、物理基线偏差
4. 类别加权 + 易碎过采样 + 强增广（继承 train_expforce_single.py 策略）。

### 3.5 实施路线

| 阶段 | 内容 | 前置 |

## 四、结论（直接回答）

1. **能实现成熟模型吗？能，且所有组件都有出处**：DINOv3 冻结骨干（调研定论）+ 层次分类（本文设计）+ (μ,σ) 力回归（dinov3_dual）+ 质量辅助（数据验证）+ 物理基线互验（已有设计）+ 安全规则层（规范要求）。数据侧 Exp-Force 129 图足够启动阶段 1。
2. **分类体系怎么选？分层四类（方案 C）**：
   - L1 易碎门控（二元，召回优先）——安全核心，对应用户"先分易碎"的直觉；
   - L2 轻脆/重脆（Exp-Force 官方分法，数据已验证）；
   - L2 刚体/柔性——**保留不合并**：合并导致柔性 F_max 高估 67%（压伤）或刚体低估 40%（滑移）+ μ 混淆 3 倍，跨相机 50%→77% 的表面提升掩盖力值系统性变差。
3. **"更细"的方向**不是加类别（样本撑不起），而是**空间化**：F_max 从物体级单一值升级为接触位置函数（壁厚/容许力图，GraspSense 路线）——这是数据到位后双流模型的正确升级方向。
4. **柔性类真正的病灶**是跨相机域差（10%），不是类别设计本身——治理手段是采集协议对齐 + 目标相机微调，与分类体系无关。
