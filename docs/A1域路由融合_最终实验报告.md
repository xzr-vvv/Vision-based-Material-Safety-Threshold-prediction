# A1 最终形态：域路由融合（视觉模型 × SigLIP 检索）— 实验报告

日期：2026-08-20
前置：SigLIP检索式A1先验_实验报告.md（检索单独验证）、增强扩充与分层架构实验报告.md（分层模型 D-G）
脚本：[fuse_visual_retrieval.py](../ExpForce数据集/fuse_visual_retrieval.py)
任务：把"分层视觉模型 E"与"SigLIP 检索先验"融合成 A1 最终形态，要求同相机与跨相机**兼得**。

## 一、融合策略对比（关键数据）

| 策略 | 同相机 25 张 | 跨相机 30 张 | 跨相机易碎 |
|---|---|---|---|
| visual（模型 E 单独） | 96% | 47% | 0% |
| retrieve（检索单独） | 88% | **77%** | **100%** |
| max（P易碎取大，召回优先） | 92% | 57% | 100% |
| weighted（0.5/0.5 等权融合） | **100%** | 57% | 60% |
| **routed（域路由）** | **100%** | **77%** | **100%** |

规律：单模态各擅一个域（视觉赢域内 96-100%，检索赢域外 77%），任何固定权重融合都无法两头最优——因为视觉模型跨相机**过度自信地错**（玻璃 P=0.04），在融合中拖累检索。

## 二、routed：SigLIP top-1 相似度做域检测器

实测发现 SigLIP 检索的 top-1 相似度是**完美的域分离器**：

| | top-1 相似度分布 |
|---|---|
| 同相机验证图（索引=训练物体） | 0.719 ~ 0.986（中位 0.900） |
| 跨相机实拍图 | 0.303 ~ 0.688（中位 0.561） |

**阈值 0.70 实现两组 100% / 0% 干净分离**（无重叠区间）。

```
routed 策略:
  top1 > 0.70  → 域内(采集协议一致) → weighted 等权融合   → 同相机 100%
  top1 ≤ 0.70  → 域外(换相机/场景)   → 检索接管(视觉不可靠) → 跨相机 77%, 易碎 100%
```

这与 ResTacVLA 的 Surprise-Aware Gate 同构：**用先验的可靠度信号决定谁接管**——我们的域检测器 = 检索 top-1 相似度，它的语义是"查询图与经验库的匹配程度"，即视觉先验在当前域的可用性度量。

## 三、A1 最终形态（定稿架构）

```
输入图片
  ├─ SigLIP-So400m 嵌入 (生产形态: 复用 π0.5 骨架内 PaliGemma 视觉塔, 零权重冗余)
  │    ├─ 检索: Exp-Force 129 物体库(+自采扩充) → 邻居投票 + 力值加权回归
  │    └─ top-1 相似度 → 域检测器 (阈值 0.70)
  ├─ 分层视觉模型 E (ResNet18, 全类背景增强训练)
  │    └─ L1 门控 P_visual(易碎) + L2 细分 + 力(μ,σ)回归 + 质量头
  └─ 域路由:
       域内 → P(易碎) = 0.5·P_visual + 0.5·P_retrieval, 细分等权融合
       域外 → 检索结果直接接管
  输出: 类别(刚体/柔性/易碎 + 轻脆/重脆) + [F_min, F_max] + 域标志 + unknown
```

最终指标（两域兼得）：**同相机 100% / 跨相机 77% / 跨相机易碎召回 100%**（视觉模型时代：96% / 47% / 0%）。

## 四、安全语义说明

- 域外(跨相机)时检索接管是**保守方向**：检索对易碎 100% 召回（错杀代价小），玻璃绝不会被当刚体抓
- 域检测器输出应写入 prior JSON（`domain_match: true/false` + top1 值），供下游触觉后验（B 级）参考——域外 + 高不确定 = 触觉接管的触发条件（ResTacVLA 范式）
- 力值：域外用检索回归（邻居实测值平移）；域内可融合视觉力头与检索（本实验未展开，后续项）

## 五、遗留与下一步

1. **柔性跨相机 50%** 仍是短板（皮革钱包→电源适配器：形状像语义不像）——库外泛化边界，需自采柔性物体入库扩充索引
2. 索引库扩充：TransCG 玻璃物 + 自采物体（每物体 1 图 + 实测力）入库即增强检索覆盖
3. 力值融合（域内视觉力头 × 检索回归的 MAE 对比实验）
4. 域阈值 0.70 目前由 25+30 张图标定，样本小；自采数据到位后重标定并验证泛化
