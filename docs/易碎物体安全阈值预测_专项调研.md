# 易碎物体安全阈值预测 — 专项调研

日期：2026-08-20
背景：易碎类是本项目当前最弱类别（仅 11 个物体，跨相机准确率 0%），且 F_max = k×F_min 为工程推算值，全球无逐物体破损阈值真值。本调研专查"预测易碎物体安全阈值"的已有项目。
检索范围：2023-2026 顶会顶会/arXiv/中文核心，关键词覆盖 fragile / damage threshold / bioyield / fracture anticipation / admissible force / slip detection。

---

## 一、一页结论

1. **直接发布"逐易碎物体破损阈值实测值"的数据集仍然不存在**（与 2026-08 前两轮调研结论一致）。最接近的三家：Exp-Force（11 个易碎物，但只有防滑下界 F_min）、草莓损伤阈值论文（3 品种，0.3-0.6N，单品类）、V2F（椰枣 bioyield，单品类）。
2. **方法论上出现三个强相关新方向**（此前调研未覆盖）：
   - **GraspSense 力图**（Skoltech 2026）：从 3D 几何壁厚推每个表面点的容许接触力——玻璃杯杯壁 69N vs 杯柄 565N，8 倍空间差异。证明"安全阈值是空间分布，不是单一值"。
   - **断裂预期 + 可牺牲替代物**（OMRON SINIC X, ICRA 2023）：用积木/乒乓球/果冻的破损经验学断裂预测，域泛化到真实食物——解决"易碎物破损数据昂贵（碎一次废一个）"的根本问题。
   - **V2F 物理信息残差网络**（IROS 2026）：Hertz 接触方程 + 神经网络残差修正，跨品种 R²≈0.7——小样本下比纯数据驱动泛化好。
3. **对本项目最直接的三条可落地增量**（详见第五节）：
   - 自测易碎物破损阈值小数据集（全行业空白，测了就是贡献）；
   - 深度流升级为"壁厚/容许力图"预测（解决 F_max 空间粒度问题）；
   - VLM 经验检索范式（Exp-Force 原方法）作为单流模型的对照基线。

## 二、Tier 1：直接预测易碎物体安全阈值的项目（5 个）

### ① Exp-Force（UT Austin, arXiv:2603.08668, 2026.03）—— 本项目数据源，方法升级版

- **做法**：单张 RGB 图 → 检索相似物体先验抓取经验 → 条件化 VLM（GPT-5.2/Gemini-3.1-Pro 级）上下文推理 → 预测最小可行抓力。
- **结果**：129 物体 MAE 0.43N（比 zero-shot VLM 降 72%）；30 个未见物体上"力度合适率"63% → 87%。
- **易碎相关细节（本次调研新发现）**：官方把 129 物体分 6 个语义类，其中**易碎被细分为 Fragile-light / Fragile-heavy 两档**（按质量切分）——比本仓库三类粗分更细，易碎类内部"轻脆（薯片）vs 重脆（果酱瓶）"的力值差异大，值得借鉴。
- **对本项目**：数据已在手；其 VLM 检索式推理可作为 ResNet18/DINOv3 判别式模型之外的对照基线；易碎二分法可直接用于 07 CSV 的类别细化。

### ② GraspSense（Skoltech, arXiv:2604.05697, 2026.04）—— 力图：安全阈值的空间分布

- **做法**：语言指令 → YOLO-World + SAM 分割 → SAM3D 单图 3D 重建 → 物理信息几何分析（主轴分解 + 柱面离散化 + **壁厚估计**）→ 计算每个表面点的**容许侧向接触力**（force map，蓝=高容许/红=低容许）→ 抓取候选用力图重排（优先接触机械强区）→ 阻抗控制按局部容许力逐指缩放刚度。
- **关键实验**：玻璃高脚杯——杯壁抓取容许力 69N vs 杯柄抓取 565N；纸杯/塑料杯/玻璃杯三类材质验证，接触区始终选在中上部结构强区。
- **对本项目（最重要启发）**：
  1. 证明"易碎物安全阈值不是物体级单一值，而是接触位置的函数"——本仓库 F_max = k×F_min 是物体级的，粒度不够；
  2. 其壁厚→容许力映射是**纯几何物理近似，不需要任何破损数据**——正好可以用我们的 RGB-D 深度流实现（深度图天然含壁厚/几何信息），这是双流模型深度流最明确的高价值任务；
  3. 论文全流程在 Isaac Sim 里做，仓库可复现。

### ③ V2F（KAUST 系, IROS 2026, arXiv:2607.19804）—— 安全抓取包络 + 物理信息残差网络

- **做法**：先力学实验标定椰枣**生物屈服点（bioyield point，不可逆细胞破裂起点）**定义安全包络 σ_max < σ_bioyield；视觉管线（Mask R-CNN 分割 + 主动轮廓细化 + 几何特征提取）→ **Hertz 接触方程为基线 + 残差神经网络修正**，复合损失 = 数据损失 + 物理一致性损失。
- **结果**：跨未见品种 GroupKFold 验证 R²≈0.74 / RMSE 1.13kPa；真机验证残余变形 <1mm 无损伤，证明"预判式视觉力估计可替代探索式触觉试探"。
- **对本项目**：
  1. "力学标定定义安全包络 → 视觉预测"的两段式范式 = 本项目 A 级目标的学术表达，可作为论文引用的方法论正统性支撑；
  2. 物理方程 + 残差的混合架构在小样本（生物组织个体差异大）下泛化好——对 129 张图规模的本项目直接适用；
  3. 单域局限（只有椰枣），无公开数据集。

### ④ 断裂预期：Learning Food Picking without Food（OMRON SINIC X + Keio, ICRA 2023）

- **做法**：机械臂 + 分布式触觉传感器**压碎**可重复使用的易碎物（玩具积木、乒乓球、果冻——覆盖 crack/rupture/crush 三种断裂类型），记录断裂瞬间的触觉信号 → 训练断裂预期网络（预测"再夹多久会碎"）→ 域泛化（DG）迁移到真实食物（豆腐/香蕉/薯片/番茄），实现断裂前一刻停止。
- **对本项目（数据策略启发最大）**：
  1. **用便宜的可牺牲物收集破损数据**，替代昂贵的真实易碎物破损实验——鸡蛋薯片测一次碎一次，成本高；乒乓球/果冻可以批量买；
  2. 三种断裂类型分类（crack 裂 / rupture 破 / crush 压溃）可作为自采易碎物数据的标注维度；
  3. 该工作用触觉信号，我们是视觉先验——但"破损数据收集协议"完全可平移。

### ⑤ 草莓视触觉损伤阈值（华南农业大学, 农业工程学报 2025）

- **做法**：Gelsight 原理视触觉指 + AFE-Unet3+ 网络，同步预测接触区域与法向力（力回归 R²=0.976）；对 3 个草莓品种做**损伤阈值试验**，实测安全夹持力范围 **0.3-0.6N**（施力 2-4N 时 8/8 全部受损）。
- **对本项目**：中文核心里少见的"逐品类实测损伤阈值"工作；其损伤阈值试验协议（分力档 × 计数受损率）可直接抄用于自采易碎物实测；0.3-0.6N 的草莓阈值可作为柔性/易碎边界样本的外部参照。

## 四、行业格局判断

```
安全阈值 = 防滑下界 F_min                    安全阈值 = 破损上界 F_max / 容许力
─────────────────────────────              ─────────────────────────────
实测真值:  Exp-Force(129物,含11易碎) ✔       实测真值:  草莓(3品种) / 椰枣(1品类) ✔ (均为单品类)
仿真估计:  SoftVTBench / OopsieVerse         仿真估计:  OopsieVerse(DamageSim) / GRIP(应力场)
几何推算:  —                                 几何推算:  GraspSense(壁厚→容许力图) ✔ 不需破损数据
语义推算:  DeliGrasp(LLM物性→公式)           语义推算:  VLM常识(Exp-Force zero-shot, MAE 1.5N 级)
触觉在线:  Gentle Grasping/ScienceAdv 滑移   触觉在线:  OMRON 断裂预期(压碎可牺牲物学习)
```

**结论**：下界（防滑）侧已有 Exp-Force 实测数据支撑；上界（破损）侧全球空白，只有单品类实测（草莓/椰枣）和无需破损数据的几何路线（GraspSense）。本项目的 F_max = k×F_min 推算策略与行业现状一致，不算落后——但存在两个明确的超越机会（见下）。
