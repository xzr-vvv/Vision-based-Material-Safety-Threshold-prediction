# 易碎 vs 刚体视觉区分难题 — 专项调研

日期：2026-08-20
问题定位（已实验证实）：跨相机测试中 5 张玻璃图 **4 张被判刚体、P(易碎) 仅 0.04-0.10**——模型极确信"不是易碎"。玻璃/陶瓷与塑料/金属罐都是光滑硬质表面，RGB 纹理差异小；且玻璃判别特征（透明、镜面高光、折射）随相机/视角/光照剧变。
本质：**易碎性是材料力学属性（弹性模量/脆性），不是纹理属性**——RGB 只是间接证据。行业四条路线如下。

---

## 一、路线对比总览

| 路线 | 代表工作 | 对玻璃 vs 塑料的效果 | 对本项目门槛 |
|---|---|---|---|
| ① 物理传感（雷达/偏振/热） | FuseGrasp / VLMaterial / ClearDepth | **96%+ 材料识别**（介电常数直接分玻璃塑料） | 需采购硬件，中 |
| ② 纯 RGB 算法 | MODEST / SR3D / 光泽感知 | 分割/深度可行，材料判别仍难 | 纯软件，低 |
| ③ VLM 语义先验 | PG-VLM(PHYSOBJECTS) / PhysBench / DeliGrasp | 依赖物体识别+常识，Exp-Force 论文即此路线 | **零硬件，已有 API 即可** |
| ④ 已有未用信号 | 深度空洞率（TransCG）/ 质量 / 形状 | 深度空洞=透明检测器；玻璃杯偏重 | 等 RGB-D 自采 / 立即可用 |

## 二、各路线详情

### ① 物理传感路线（最根本，绕开视觉歧义）

- **FuseGrasp**（CUHK, IEEE TMC 2025）：毫米波雷达+相机融合。mmWave 穿透性弱，透明材料在雷达图上"不透明"，**副产品就是玻璃/塑料材料识别，直接用于调节抓力**——与本项目目标完全同构（深度补全 + 材料识别 + 力调制）。两阶段训练：大 RGB-D 数据预训练 + 小雷达集微调。
- **VLMaterial**（CUHK, arXiv:2604.11671）：VLM + 毫米波介电常数融合，training-free。动机原文就是"distinguishing between visually similar objects, **such as a glass cup versus a plastic one**"。41 物体 120 实验，96.08%，能识别 4 类视觉欺骗仿冒品。**与本项目"玻璃杯 vs 塑料杯"问题一字不差**。
- **偏振成像**：偏振相机捕捉表面法线/材料信息（人眼不可见），ClearDepth（汉堡大学，IROS 系）用偏振双目恢复透明物深度；超构透镜偏振相机（Science Advances 2025.10）在小型化。偏振是玻璃(高偏振反射) vs 塑料(部分偏振)的物理判别器。
- 启示：若项目二期可加传感器，**低成本毫米波雷达或偏振相机**是易碎检测的根治方案；B 级 shadow 数据规范里可预留传感器接口。

### ② 纯 RGB 算法路线

- **MODEST**（地瓜机器人+CASIA, ICRA 2025, 开源）：单目 RGB 透明物分割+深度多任务，语义-几何融合+迭代解码，即插即用。启示：透明物**分割**可行（比材料判别容易），可先用其分割输出作为"疑似易碎"区域特征喂给我们的门控头。
- **SR3D**（北大, 2025）：单视图 RGB-D + 3D 重建绕开深度失效。
- **光泽/高光感知**（视觉科学，Fleming 组）：人眼判光泽只需**单层卷积**级别的浅层计算（Nature Human Behaviour 2026），弱标签即可预测感知光泽（CGF 2024）。玻璃 vs 塑料的物理差异恰好体现在**高光形态**：玻璃镜面高光锐利+背景透射扭曲，塑料有次表面散射（高光发糊）。**当前 ResNet18 + 224×224 输入可能丢失高频高光细节**——提高输入分辨率到 384/512 + 高光区域增强是纯软件可试的方向。
- 材料指纹（RSOS 2025）：CLIP 特征 + MLP 两张图即可预测人类材料感知——**CLIP/DINOv3 特征空间里材料信息存在**，我们的冻结骨干路线（DINOv3）理论可行，问题在训练信号量。

### ③ VLM 语义先验路线（零成本，最对症）

- **PHYSOBJECTS / PG-VLM**（斯坦福+谷歌, CoRL 系）：39.6K 众包 + 417K 自动**物理概念标注（含 fragility 脆弱性、材料）**，微调 VLM 后对保留概念泛化。**这是与我们任务最贴的公开数据集**——可下载用于蒸馏/预训练我们的易碎门控头。
- **PhysBench + PhysAgent**（ICLR 2025）：75 个 VLM 测评发现常识强但物理弱；PhysAgent = VLM + 专用视觉模型，GPT-4o 提升 18.4%。启示：**VLM 语义先验与专用视觉模型融合**正是我们"分层模型 + VLM 先验"的混合架构。
- **DeliGrasp**（CU Boulder）：LLM 从语义推 m/μ/k → 白盒公式。
- **Exp-Force 原论文**：VLM 经验检索（同类物体抓取经验 + 上下文推理）MAE 0.43N——**比我们当前判别式模型 0.50N 还好**，且 30 未见物体力度合适率 87%。它靠的就是"看到物体名 → 常识知道玻璃易碎"。
- 落地方式：物体识别（我们数据集自带物体名/或用开放词汇检测器）→ 材料/易碎语义查表（PHYSOBJECTS 知识）→ 作为 L1 门控的先验特征或交叉验证。玻璃杯叫 glass，VLM 不会错——**视觉分不出的，语义直接给出**。

### ④ 已有未用信号（立即可做）

1. **物体形状先验**：Exp-Force 易碎 11 物体 = 高脚杯×3 + 玻璃杯×3 + 蛋×2 + 薯片 + 果酱瓶 + 陶瓷杯——**杯/瓶轮廓本身就是强先验**（当前模型在素色背景下学到了，跨相机丢失——因为背景增强后轮廓特征被稀释）。形状特征（细长杯型、杯口椭圆）对域差更稳定。
2. **质量头输出**：玻璃杯中位质量 245g vs 塑料杯 ~10g——质量估计偏高 → 易碎嫌疑上升。我们的分层模型已有质量头，但推理时没用它反哺门控。
3. **深度空洞率**（等自采 RGB-D）：TransCG 证明透明物深度打穿——空洞率 > 阈值 = 透明物 = 易碎。dinov3_dual 已实现空洞率统计，双流阶段直接作为门控特征。

## 三、对本项目的行动建议

| 优先级 | 行动 | 依据 | 成本 |
|---|---|---|---|
| **P0** | **VLM/语义先验融合**：分层模型加"语义易碎先验"输入（物体名→材料常识查表，或直接用 CLIP zero-shot 材料 prompt "a photo of glass/ceramic vs plastic/metal"），与视觉门控融合（PhysAgent 式） | Exp-Force 原路线 MAE 0.43N；PHYSOBJECTS 有 fragility 标注可下载；CLIP 本地可跑 | 低（GPU 已就绪） |
| **P0** | **高光/光泽增强实验**：输入分辨率 224→448，训练时加高光扰动增广，考察玻璃高光锐度特征是否被 ResNet18@224 丢失 | 光泽感知浅层网络即可（NHB 2026）；玻璃/塑料高光形态有物理差异 | 低 |
| **P1** | 形状特征强化：杯/瓶轮廓分割（可用 MODEST 开源模型）+ 轮廓特征喂门控；推理时质量头输出反哺门控（质量>150g 且杯型 → 易碎嫌疑） | 形状/质量对域差稳定，跨相机丢失少 | 中 |
| P2 | 下载 PHYSOBJECTS 数据集，蒸馏其 fragility 标注进门控头 | 39.6K fragility 标注与任务完全同构 | 中 |
| P3 | 硬件评估：偏振相机或毫米波雷达（FuseGrasp/VLMaterial 同款思路），写入 B 级数据规范 | 96% 材料识别的根治方案 | 高（采购） |

## 四、核心判断

1. **用户诊断正确且重要**：易碎/刚体区分的瓶颈不是数据量而是**信号本身**——RGB 纹理不含脆性信息，玻璃的间接视觉证据（透明/高光/折射）又恰好是跨域最不稳定的特征。继续堆 RGB 增强收益有限（我们 7 组实验已证明）。
2. **短期最优解是语义先验**（P0）：人类靠"这是玻璃杯"的常识而非纹理判易碎，VLM 同样如此；Exp-Force 论文的 0.43N 就是证据。这条路线与分层架构天然兼容：语义先验作为 L1 门控的第二个输入。
3. **中期解是深度空洞 + 形状/质量**（P1-2，自采 RGB-D 后）：透明物深度打穿是物理必然，空洞率是免费的透明检测器。
4. **长期根治是物理传感**（P3）：毫米波/偏振直接测材料，视觉歧义被绕开。
